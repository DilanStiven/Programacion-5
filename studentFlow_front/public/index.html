Recordatorios

Consulta y administra los recordatorios asociados a tus tareas. Las tareas y materias se consultan para mostrar su contexto; esta aplicación solo escribe en la tabla de recordatorios.

Consultar un recordatorio

GET /api/v1/recordatorios/:id

Elige un ID de la lista.

Aquí aparecerá el recordatorio.

Crear recordatorio

POST /api/v1/recordatorios

La tarea debe pertenecer al usuario actual.

Reemplazar recordatorio

PUT /api/v1/recordatorios/:id

Envía todos los campos para reemplazar el registro.

Actualizar campos

PATCH /api/v1/recordatorios/:id

Completa únicamente los campos que deseas modificar.

Eliminar recordatorio

DELETE /api/v1/recordatorios/:id

Solo se elimina el registro de recordatorio.

El usuario de esta versión de clase es el usuario temporal 1 del backend. Los IDs de tarea se pueden consultar en la base de datos o en el listado de tareas de una materia.
